A collection of simplistic SOFA simulations primarily developed within the CloSer project. The scenes are generally designed to be simulated approximately in real-time and therefore rather simplistic. Multiple visitors can simultaneously interact with the simulations and adjust the settings etc. as each simulation runs in a separate process. If the server becomes overloaded by too many visitors then the maximum number of concurrent simulations may be constrained, or other measures applied. The source is public, so you can also clone it and run simulations locally, either natively using SOFA or in a container. More complex and realistic simulations are conducted offline by the team on different computers.
