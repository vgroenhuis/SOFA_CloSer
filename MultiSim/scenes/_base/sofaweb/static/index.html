How it runs here

			
    
				
  • The original SOFA scene script runs unmodified in this container, headless. Its OpenGL visual models are swapped for SOFA's GL-free VisualModelImpl as the scene is built, and their vertex positions are streamed to your browser, which draws them with three.js using the scene's own camera, lights and colors.
    • 
				
  • Parameters come from the scene's own params.json (labels from its parameter editor). Changing one rebuilds the scene from scratch, exactly like the SOFA GUI's Reload; fields marked live are applied to the running simulation instead.
    • 
				
  • The simulation never runs faster than real time; the × real time figure shows when it can't keep up.
    • 
				
  • Every run is recorded: once it's paused or finished, the timeline below plays it back at real speed (or faster or slower) and lets you scrub through it. After ■ (back to the start), the run before it stays on the timeline until the simulation runs again. A run of a preset's parameters is kept on the server, so the next simulation of that preset plays it back straight away instead of simulating it again (Simulate live runs it anyway). Other runs are only kept until the parameters change or the simulation ends.
    • 
				
  • Drag to rotate (or pan, in 2D scenes), right-drag to pan, scroll to zoom. Your view is your own.
